# Requêtes SQL

Mes requêtes SQL, classées par thème, avec les schémas sur lesquels elles tournent.

## Organisation

- `schemas/` : scripts de création des tables et jeux d'essai.
- `requetes/` : les requêtes, un fichier par exercice ou par thème (sélections, jointures, agrégats, sous-requêtes, mises à jour).

## Conventions

- Un fichier `.sql` par sujet, avec en commentaire d'en-tête la question posée et le SGBD visé (Oracle, MySQL, PostgreSQL), car la syntaxe diffère.
- Les mots-clés SQL en majuscules, les noms de tables et de colonnes en minuscules.
- Aucun identifiant ni mot de passe de base de données dans ce dépôt.
